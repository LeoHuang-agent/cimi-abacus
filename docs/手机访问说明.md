# 手机打不开 / 不稳定 — 原因说明

## 根因（不是 App 坏了）

当前「方案 B」依赖：

1. **电脑开着**，并且 `npm run preview` 在跑  
2. 手机和电脑在 **同一个 Wi‑Fi**  
3. 地址里的 IP 必须是 **当前电脑的局域网 IP**

因此会出现：

| 情况 | 结果 |
|------|------|
| 电脑休眠 / 关了预览 | 手机打不开 |
| Wi‑Fi 重连后 IP 变了 | 旧链接失效（例如从 `.212` 变成 `.178`） |
| 换了网络 / 用了流量 | 打不开局域网地址 |
| Cursor 重启杀了进程 | 需要重新启动预览 |

这是局域网调试方式的固有限制，不是报价逻辑问题。

## 临时用法（在家调试）

电脑执行：

```bash
cd "/Users/ww/Cimi小算盘"
npm run build
npm run preview -- --host 0.0.0.0 --port 4173
```

然后查当前 IP：

```bash
ipconfig getifaddr en0
```

手机 Safari 打开：`http://【当前IP】:4173/`  
（IP 每次可能不同，不要用几天前的旧地址。）

## 稳定用法（推荐）

要「固定链接、出门也能用、装一次长期离线」，需要二选一：

1. **部署到公网**（Vercel / Cloudflare Pages）→ 得到 `https://xxx.vercel.app`  
   → Safari 打开一次 → 添加到主屏幕 → 之后可离线  
2. **装完整 Xcode**，用 Capacitor 装成真正的 iPhone App  

局域网预览只适合开发，不适合当日常 App 入口。
